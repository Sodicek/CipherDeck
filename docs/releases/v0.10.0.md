# CipherDeck v0.10.0 — Bilingual Edition

CipherDeck now speaks Czech and English across the entire application.

## Highlights

- switch the interface instantly with the new `EN/CZ` button;
- keep the selected cipher, key, input, and output while switching languages;
- remember the language choice for the next launch;
- use localized cipher names, validation messages, challenges, detection results, Learn Mode explanations, history, help, dialogs, and share cards;
- keep old history and settings compatible through stable cipher identifiers;
- apply culture-aware number and percentage formatting;
- verify Czech and English resource completeness automatically.

## Quality

- 115 automated tests;
- warning-free Release build;
- formatting verification in CI;
- portable self-contained Windows x64 package, with no separate .NET installation required.

## Package

Download `CipherDeck-v0.10.0-win-x64.zip`, extract it, and run `CipherDeck.exe`.

SHA-256 is published alongside the package in this release.

> Classic ciphers are intended for learning and entertainment, not for protecting passwords or sensitive data.
